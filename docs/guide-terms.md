# Terms

Words that mean the same thing in MyOrdbok, one group a line, separated by
commas. A group must not hold a word that means something else elsewhere in
the guide ("test" belongs to the tests, so it is not a name for beta): every
word of a group stands for every other. The Guide (`shared/guide/index.js`, `TERMS_FILE`) reads a question
with one of them as also asking for the others, at a little less weight,
so "lemma" finds what is written about headwords. This file is not shown
as a page.
